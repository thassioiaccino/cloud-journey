## 🐧 Project 001 — Linux Server: Provisioning & Administration

**Status: ✅ Completed**

The first project starts at the foundation: administering a Linux server from a blank virtual machine and taking it to an operational, testable and documented state.

The project covers:

- Linux Server provisioning in VMware;
- NAT networking and remote administration with SSH/PuTTY;
- users, groups, ownership and filesystem permissions;
- package management with APT;
- Nginx installation and Web publishing;
- services and processes with `systemd`;
- system, SSH and Nginx logs;
- process signals and controlled termination;
- environment variables;
- Bash health-check automation;
- scheduled execution with `cron`;
- controlled Nginx failure, troubleshooting and recovery;
- final technical review and validation.

## 📐 Project Standard

Every finished project should demonstrate more than a list of commands. The documentation should make clear:

**🎯 Problem** — what scenario or engineering challenge is being solved.  
**🏗️ Architecture** — how the environment and components fit together.  
**🔧 Implementation** — what was built and the relevant technical decisions.  
**🧪 Validation** — how the expected behavior was verified.  
**💥 Troubleshooting** — at least one meaningful failure, investigation and recovery when applicable.  
**💡 Learnings** — what changed in my understanding after building it.  
**🚀 Next steps** — how the project could evolve into a more mature architecture.
